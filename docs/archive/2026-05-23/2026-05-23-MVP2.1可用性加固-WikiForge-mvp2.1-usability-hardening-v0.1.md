## 契约冻结

### 新增 API

```text
GET /api/v1/source-files/{fileUid}/obsidian-note
```

返回：

- 若存在 Note：`ApiResponse<ObsidianNoteResponse>`
- 若不存在 Note：`ApiResponse<null>`

```text
GET /api/v1/obsidian/status
```

返回 `ObsidianVaultStatusResponse`：

- `vaultName`
- `vaultPath`
- `exists`
- `writable`
- `sourceNoteDirectoryExists`
- `lastNoteUid`
- `lastWrittenAt`
- `errorMessage`

### 扩展 SourceFileResponse

Source Files 列表增加最新 Obsidian Note 摘要字段：

- `obsidianNoteUid`
- `obsidianNoteStatus`
- `obsidianNoteTitle`
- `obsidianVaultPath`
- `obsidianUri`
- `obsidianNoteCreatedAt`

## 重复写入策略

MVP2.1 第一轮不做覆盖、另存、版本化三选一 UI。

默认策略：

- Source File 已存在 Note 时，表格按钮进入“预览已有 Note”。
- Source File 未存在 Note 时，表格按钮进入“生成草案并写入”。
- 不自动重复写入。
- 后续 R1-3 再设计覆盖 / 另存 / 版本化策略。
