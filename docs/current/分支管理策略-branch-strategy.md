# WikiForge 分支管理策略 Branch Strategy

## 版本信息

- 文档版本：v0.3
- 生效日期：2026-05-24
- 当前适用阶段：MVP0 重新开始

## 核心原则

- `main` 是稳定主干。
- 日常开发使用短生命周期任务分支。
- 历史分支只用于追溯，不作为当前阶段依据。
- 不自动删除远程历史分支。

## 分支类型

| 类型 | 命名 | 用途 |
| --- | --- | --- |
| 主干 | `main` | 稳定主线 |
| MVP0 任务 | `codex/mvp0-*` | 当前重构、设计、功能开发 |
| 修复 | `codex/hotfix-*` | 紧急修复 |
| 实验 | `codex/exp-*` | 明确的短期验证 |

## 使用规则

- 新任务优先从当前工作分支继续，除非用户要求新分支。
- 大改动可创建 `codex/mvp0-{topic}`。
- 提交前必须运行本节点要求的验证命令。
- 合入 `main` 前必须确认没有 Raw Sources、Obsidian Vault、本地数据或 `.env`。

## 历史分支

已有 `codex/mvp*`、`codex/r*` 或其他历史分支只保留为追溯材料。是否删除必须由用户确认。
